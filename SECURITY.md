# Security Policy

## Supported Versions

Security maintenance focuses on the latest published release
of the Derivatives Pricing Laboratory.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately
through GitHub's private vulnerability reporting feature
under the repository's Security tab.

Do not disclose credentials, sensitive information, or
unresolved vulnerabilities in public issues.

## Security Practices

The laboratory uses automated testing, dependency monitoring,
code scanning, secret scanning, input validation, and bounded
computational workloads.

## Application Scope

The application is intended for educational and computational
research using synthetic model parameters. It does not require
personal financial information or account credentials.

No software system can guarantee complete security.
